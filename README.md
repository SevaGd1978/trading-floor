# Торговый зал — четыре бота спорят о рынке

Онлайн: https://sevagd1978.github.io/trading-floor/

Откройте ссылку в Chrome на телефоне. Затем меню Chrome → «На экран Домой», чтобы зал жил как приложение.

Это не инвестиционная рекомендация. Боты работают по простым детерминированным правилам, решение принимает человек. Кнопки «Купить / Ждать / Пропустить» только записывают решение в журнал браузера (localStorage). Никаких заявок на биржу не отправляется. Прибыль не гарантируется.

## Как открыть локально
1. **Статический сайт / GitHub Pages:** золото, EUR/USD и BTC берутся напрямую с Binance (для золота это PAXG, для евро EUR/USDT, цена близка к оригиналу, но не равна ему), новости идут через rss2json. Нефть, USD/RUB и S&P 500 на статическом хостинге показываются из снимка `snapshot.js`, если живой источник недоступен; снимок помечен временем и это не текущие цены.
2. **Полные живые данные по всем 6 инструментам:** `python3 serve.py` → открыть http://localhost:8765 . Тогда котировки идут с Yahoo Finance, новости — из Google News.
3. Обновить снимок: `python3 make_snapshot.py`.

## Боты
- **Сканер** (ищет объём) сравнивает объём последнего закрытого часа со средним за 20 баров (порог ×1,5), измеряет размах свечи в ATR и смотрит, где цена относительно максимума и минимума за сутки и круглых уровней. Если объёма в источнике нет (FX), он так и пишет.
- **Новости** (читает ленту) берут Google News RSS на русском и выбирают свежий заголовок за 72 часа, отдавая приоритет макро-словам (ФРС, ставка, ОПЕК…). Тон заголовка определяется по ключевым словам. Если ленты нет, бот так и говорит.
- **Трейдер** (вход / выход) определяет тренд по SMA20 и SMA50. Вход ставит на откате 0,3 ATR, стоп за ближайшим свингом (от 1 до 3 ATR), тейк на 2R. Если тренда нет, пишет «сетапа нет».
- **Скептик** (спорит) смотрит три независимых подтверждения: объём, новости по направлению сделки и пробой уровня. Два или больше означают «вход». Одно означает «ждать ретест». Ноль означает «Рано. Подтверждения нет». Новости против сделки означают «пропустить».
